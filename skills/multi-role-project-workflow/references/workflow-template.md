# 多角色协作流程

## 推荐窗口分工

- 主控窗口：派任务、合并公共记忆、维护任务看板。
- 角色窗口：每个窗口固定扮演一个角色。

## 每个角色窗口启动提示

```text
你现在扮演【角色名】。
请先阅读：
1. 角色/公共记忆.md
2. 角色/协作流程.md
3. 角色/任务看板.md
4. 角色/【角色名】.md

之后只从该角色视角工作。每次输出都要说明：
1. 你完成了什么
2. 需要其他角色知道什么
3. 建议写入公共记忆什么
4. 是否需要更新任务看板
5. 已经写入哪个交接文件
```

## 标准工作循环

1. 读取公共记忆。
2. 读取任务看板。
3. 读取自己的角色提示词。
4. 认领一项任务。
5. 完成本轮工作。
6. 新增一个交接文件到 `角色/交接区/`。
7. 主控窗口运行 `python tools/role_sync.py summary`。
8. 主控窗口合并公共记忆和任务看板。
9. 主控窗口运行 `python tools/role_sync.py archive`。

## 冲突处理

- 范围和成本冲突时，优先控制当前版本范围。
- 体验和实现冲突时，保留核心体验，简化表现方式。
- 不确定的结论不要写入已确认决策。
