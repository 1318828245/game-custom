- 新增奖励道具实体 `RewardPickup`。
- 战斗房清空后会生成一个可拾取奖励。

运行方式：

```bash
python main.py
```

人工验证建议：

- 进入战斗房 1，清空敌人后确认房间中央出现 `Heal +1` 奖励。
- 玩家接触 `Heal +1` 后奖励消失，HUD 显示拾取提示，生命值恢复但不超过最大生命。
- 进入战斗房 2，清空敌人后确认房间中央出现 `Rapid Fire` 奖励。
- 玩家接触 `Rapid Fire` 后奖励消失，HUD 中 `Fire cooldown` 数值降低。
- 拾取奖励后再进入下一房间，确认上一房间奖励不残留。
- Boss 房清空后确认直接显示 `PROTOTYPE COMPLETE`。
- 确认 `Esc` 和关闭窗口仍可正常退出。

## 4. 当前实现说明

- `RoomDefinition` 新增 `reward_type` 字段，用简单代码配置每个房间清空后的掉落类型。
- 当前房间奖励配置：
  - `Combat Room 1`：`heal`
  - `Combat Room 2`：`fire_rate`
  - `Boss Room`：无奖励，清空后显示原型完成。
- `RewardPickup` 只负责奖励道具的可见占位、碰撞检测和标签显示。
- `GameApp` 负责奖励生成、拾取和效果应用。
- 玩家射击冷却从固定常量改为 `GameApp.player_fire_cooldown`，便于奖励修改。
- 玩家弹体 `Projectile` 支持传入伤害值，为后续伤害提升奖励保留扩展点。
- 当前奖励系统没有随机掉落、没有三选一界面、没有稀有度、没有背包和存档。

## 5. 建议写入公共记忆的确定结论
