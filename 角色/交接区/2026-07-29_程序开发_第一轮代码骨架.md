## 3. 当前运行方式

正常启动：

```bash
python main.py
```

退出方式：

- 点击窗口关闭按钮。
- 按 `Esc`。

自动烟测方式：

```bash
$env:SDL_VIDEODRIVER='dummy'
$env:GAME_CUSTOM_SMOKE_TEST='1'
python main.py
```

`GAME_CUSTOM_SMOKE_TEST=1` 时会运行 3 帧后自动退出，便于后续自动验证。
